# Sound Repair Studio — Landing Page (Portfolio / Demo)

ギター・ベースのリペア工房を想定した1ページ構成のランディングページです。
実案件をベースにした **ポートフォリオ用のデモ** で、実在の個人情報・連絡先・ブランドは伏せ、すべてダミー値に置き換えています。

## 概要
- 静的サイト（HTML / CSS / バニラ JavaScript・ビルド不要）
- モバイルファーストのレスポンシブ設計
- 日本語タイポグラフィのモバイル最適化（iOS WebKit での折り返し崩れ対策）
- スクロール連動のフェードイン演出（IntersectionObserver）
- サービス紹介のタブ切替・予約フォームのバリデーション（バニラJS）

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | トップページ |
| `privacy.html` | プライバシーポリシー |
| `style.css` | スタイル（レスポンシブ） |
| `script.js` | タブ切替・スクロール演出・フォームのバリデーション |
| `image/hero.jpg` | ヒーロー画像 |

## デモ仕様（ご注意）
- ブランド名「Sound Repair Studio」・代表者名・住所・電話番号・各種許可番号は **すべてダミー** です。
- ロゴはテキストのワードマークに置き換えています（実ロゴ画像は非公開）。
- 予約フォームは **デモで、実際には送信されません**（外部送信先は削除済み）。
