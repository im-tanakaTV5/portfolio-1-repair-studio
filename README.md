# Sound Repair Studio — Landing Page (Portfolio / Demo)

ギター・ベースのリペア工房を想定した1ページ構成のランディングページです。
実案件をベースにした **ポートフォリオ用のデモ** で、実在の個人情報・連絡先・ブランド・地名は伏せ、すべてダミー値に置き換えています。

公開ページ: https://im-tanakatv5.github.io/portfolio-1-repair-studio/

## 概要
- 静的サイト（HTML / CSS / バニラ JavaScript・ビルド不要）
- モバイルファーストのレスポンシブ設計
- 日本語タイポグラフィのモバイル最適化（iOS WebKit での折り返し崩れ対策・見出しの確定改行）
- スクロール連動のフェードイン演出（IntersectionObserver）
- サービス紹介のタブ切替（6事業。キーボードの矢印・Home/End にも対応）
- スタジオレンタルの料金表・2スタジオの設備・予約ページへのボタン
- 事業者情報（営業時間・定休日・アクセス）と SNS（X / LINE）の一覧、LINE 公式アカウントの告知
- スマホのメニュー（開いている間は背面のスクロールを固定し、SNS アイコンを表示）
- 予約フォームのバリデーション（電話番号欄あり）・入力欄をラベルと枠で1つにまとめたデザイン
- セクション背景の交互配色
- SEO：検索向けの title / description、構造化データ（LocalBusiness の JSON-LD）
- 表示の軽量化：ヒーロー画像は WebP の3サイズ（srcset）、Web フォントは使うウェイトだけ読み込み

## デモ仕様（ご注意）
- ブランド名「Sound Repair Studio」・代表者名・住所・地名・電話番号・メールアドレス・営業時間・各種許可番号は **すべてダミー** です。
- ロゴはプレースホルダ／テキストのワードマークに置き換えています（実ロゴ画像は非公開）。
- X・LINE・予約ページへのリンクは **デモのためリンク先がありません**（押しても移動しません）。
- 予約フォームは **デモで、実際には送信されません**（外部送信先は削除済み）。
